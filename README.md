```json

  "buildings": [{
    "id":       "boyd_orr",
    "name":     "Boyd Orr",
    "lat": 55.872, "lng": -4.291,
    "opens":    480,
    "closes":   1320,
    "lectures": [{ "subject": "Computing Science", "start": 600, "end": 720 }],
    "isOutdoor": false
  }],

  "students": [{
    "id": "S001", "name": "Finn Carter",
    "age": 21, "sex": "M", "year": 3, "subject": "Computing Science",
    "height": 178, "hair": "#3d2b1f",
    "societies": ["Chess Club", "Film Society"],
    "score":   8.2,

    }],

    "claims": [{ "place": "boyd_orr", "start": 480, "end": 600, "activity": "lecture", "society": null }],
    "testimony":     "I had my Computing Science lecture in Boyd Orr first thing...",
    "llm_reasoning": "The student claims a library visit 19:00-21:00 but no log entry exists..."
  }],

  "edges": [{
    "a": "S001", "b": "S007",
    "weight": 0.91, "overlap_min": 55, "place": "kelvingrove"
  }],

  "findings": [{
    "rank": 1,
    "text": "Two students were in Kelvingrove Park together from 03:38 to 05:33, when no building is open.",
    "time_start": 218, "time_end": 333,
    "place": "kelvingrove",
    "students": ["S001", "S007"]
  }],

  "kingpin": "S007"
}
```

**All times = minutes after midnight.** `480` = 08:00. `218` = 03:38.

## 🐍 Python Pipeline

### Stage 1 · `ingest.py` — Rohit

- Parse `"0338-0716"` → `start=218, end=436`
- Parse `"{55.87 -4.29}"` → `lat=55.87, lng=-4.29`
- Parse `"Chess Club; Drama"` → `["Chess Club", "Drama"]`
- Build **subject alias dict** (`"Computer Science"` → `"Computing Science"`)
- Build **building alias dict** (`"Boyd Orr Bldg"` → `"Boyd Orr"`)
- Print any unmatched names as warnings
- Write `extra_places.csv` for Kelvingrove, QMU, etc.

### Stage 2 · `lectures.py` — Bhushan

- Use `re.findall()` on building descriptions to extract lecture windows
- Output: `building | subject | start_min | end_min`
- Use `findall` not `search` — one description can list several subjects

### Stage 3 · `claims.py` — Shradha

- Send each testimony to Claude with a fixed JSON output schema
- Schema: `{ place, start, end, activity, society }`
- **Cache every response to `data/llm_cache/` immediately**
- Re-running reads from cache — no live API call on demo day

### Stage 4 · `rules.py` — Bhushan

| Rule | What it detects |
|------|----------------|
| `OOH` | Stay in a building outside its `opens`/`closes` window |
| `NIGHT` | Any stay anywhere between 00:00 and 06:00 |
| `LECTURE` | No stay in the right building during the lecture window |
| `TELEPORT` | Overlapping stays at different places, or gap too short to walk at 5 km/h |
| `TESTIMONY` | Claim with no matching log, unmentioned stay, or invalid society |
| `IDENTITY` | Name in log differs from student table for same ID |

### Stage 5 · `graph.py` — Shradha

- Two students are linked if their stays overlap at the same place for ≥ N minutes
- Edge weight = `overlap_minutes / place_occupancy` (crowd correction — stops lecture halls linking everyone)
- **Kingpin** = student with low flag score + highest weighted degree

### Stage 6 · `build.py` — Shradha

- Combine flags into score 0–10 per student
- Write `findings[]` as plain English sentences with time + place + students
- Assemble and write `web/data.json`

## 🌐 Browser App

### Shared State (`app.js` — Danielle)

```js
const state = {
  currentTime:     null,   // minutes after midnight — drives clock + map
  selectedStudent: null,   // student ID — drives card + highlights
  mode:            'map',  // 'summary' | 'map' | 'story' | 'evidence'
  storyStep:       0,      // index into findings[]
  revealMode:      false   // true = show kingpin links + fade clean students
}
```

Every view reads from and writes to `state`. Changing one thing updates everything else.

### Module Ownership

| File | Owner | Job |
|------|-------|-----|
| `summary.js` | Danielle | Opening screen: suspect count, kingpin tease, top 3 findings |
| `timeline.js` | Danielle | D3 swimlane: one lane per student, flag bars, scrubber |
| `network.js` | Danielle | D3 force graph: kingpin centred, edge width = weight, reveal animation |
| `map.js` | Som | SVG campus map: animated markers, trails, building polygons, clock |
| `story.js` | Som | Story mode: steps through findings, flies map, jumps clock |
| `card.js` | Som | Interrogation card: testimony vs logs, contradictions in red, flag chips, LLM reasoning |
| `speech.js` | Som | `window.speechSynthesis` wrapper — reads card aloud |

### Map Layer Design

```
SVG Canvas
├── Background (grass, River Kelvin, roads)
├── Building layer  — one shape per building, labelled "Boyd Orr · 08–22"
├── Trail layer     — fading path behind each flagged student
├── Marker layer
│   ├── Clean students:   faint grey, 40% opacity
│   ├── Flagged students: bright colour, pulsing alert ring
│   └── Kingpin:          looks clean → gold + dashed links on reveal
└── Clock overlay   — top-right corner, HH:MM + sun/moon icon
```

```

│  FINN CARTER   score: 8.2   [TELEPORT] [NIGHT]  🔊  │
```

Three things happen on click: card opens, map flies to the contradiction building, timeline jumps to that moment.

## ⚠️ Risks & Fixes

| Risk | Fix |
|------|-----|
| Name mismatches between CSVs | Rohit's alias dicts + unmatched-name printer in `ingest.py` |
| LLM API down at venue | Shradha caches every response — `llm_cache/` is the source of truth |
| Crowded lecture halls link everyone | Weight edges by `1 / occupancy` in `graph.py` |
| No wifi at venue | `data.json` pre-committed; SVG map is fully offline |
| Speech voice differs on demo laptop | Test Friday night; text always visible on screen |
| Integration chaos at 5:30 | Som + Danielle use mock data all day — swap is one file copy |
